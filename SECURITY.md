# Security policy

AI OS is experimental software. Please do not disclose a suspected security
issue in a public issue if it could expose credentials, host files, or VM escape
behavior.

Open a private GitHub security advisory when available, or contact the
maintainer through the GitHub profile for `noktirnal42`. Include a minimal
reproduction, affected path, and whether the issue crosses the `/ai` boundary.

The emulator is the supported development target. Do not test escape techniques
against systems you do not own.
